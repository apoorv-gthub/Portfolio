# Apoorv Lambe — Portfolio

A responsive, static portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and SEO metadata
- `css/style.css` — responsive design and visual styling
- `js/script.js` — navigation, preloader, scroll progress and reveal effects
- `assets/images/apoorv-profile.jpeg` — supplied profile picture
- `assets/certificates/` — reserved for certificate files if you later want to store local copies
