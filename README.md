## 🎨 Features & Highlights

- **Interactive Code Canvas:** Custom terminal/code snippet block presenting background information using Java syntax.
- **Projects Showcase:** Highlights key projects including backend applications (Java/JDBC/MySQL) and web interfaces.
- **Toolbox & Skills Breakdown:** Dedicated section categorizing core languages, database management, and CS fundamentals.
- **Responsive & Lightweight:** Optimized for desktop and mobile performance built using pure, modern web standards.

## 🛠️ Tech Stack & Technologies Used

- **Frontend:** HTML5, CSS3, Modern JavaScript (DOM Manipulation)
- **Design & Typography:** Google Fonts, Custom CSS Variables, Flexbox/Grid
- **Hosting & Deployment:** GitHub Pages
