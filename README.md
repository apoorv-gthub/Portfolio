# Apoorv Lambe — Portfolio

A responsive, static portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Deploy to GitHub Pages
1. Create a repository (or use your existing portfolio repository).
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
