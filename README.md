# Apoorv Lambe — Portfolio

Static portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure/content
- `style.css` — responsive styling and animations
- `script.js` — theme toggle, mobile navigation and reveal animations
- `favicon.svg` — favicon
- `resume.pdf` — add your resume here

## Before deploying
1. Replace `YOUR-DOMAIN.com` in `index.html` with your real domain.
2. Put your resume in the root folder as `resume.pdf`.
3. Replace the `YOUR PHOTO` placeholder in `index.html` with your image when ready.
4. Test all links.
